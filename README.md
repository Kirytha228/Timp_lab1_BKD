# GitLab — каталог файлов журнала

Студент: Бойков К.Д., группа 714-1  
Вариант: 2 «Каталог файлов журнала»

## Назначение

Администратор оценивает объём файлов журналов перед копированием.
Программа работает с подготовленным в коде списком метаданных
(Name, SizeKb, Extension): не ищет файлы на диске, ничего не копирует
и не удаляет.

## Начальная программа

Базовая версия выводит поле Name всех записей в исходном порядке:
audit, notes, trace, empty. Отбор (Selection) возвращает набор без
изменений, сводка (Summary) — пустую строку.

## Запуск

```
dotnet run
```

Тестовые наборы выбираются аргументом: `dotnet run -- empty`,
`dotnet run -- zero`, `dotnet run -- upper`, `dotnet run -- custom`.
