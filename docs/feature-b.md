# Функция B — суммарный размер (ветка feature/size-summary)

## Цель

Сложить SizeKb всех переданных записей и вывести итог строкой
`SumKb: {сумма}`. Считается размер именно переданного набора, а не
количество имён. Для пустого набора сумма равна 0. Формат строки
записи: `{Name}; size={SizeKb}`. Отбора в этой ветке нет, поэтому
выводятся все исходные записи.

## Проверки

| Запуск | Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| `dotnet run` | audit/120/log, notes/20/txt, trace/80/log, empty/0/log | 4 строки `{Name}; size={SizeKb}`, затем SumKb: 220 | audit; size=120, notes; size=20, trace; size=80, empty; size=0, SumKb: 220 |
| `dotnet run -- empty` | пустой массив | только SumKb: 0 | только SumKb: 0 |
