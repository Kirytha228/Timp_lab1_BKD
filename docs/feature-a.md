# Функция A — отбор файлов журнала (ветка feature/log-filter)

## Цель

Оставить в наборе только записи с расширением `log`. Сравнение
учитывает регистр (`LOG` и `Log` не подходят), файлы нулевого размера
сохраняются, исходный порядок не меняется. Формат строки:
`{Name}.{Extension}`. Сводки в этой ветке нет.

## Проверки

| Запуск | Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| `dotnet run` | audit/120/log, notes/20/txt, trace/80/log, empty/0/log | audit.log, trace.log, empty.log (3 строки) | audit.log, trace.log, empty.log (3 строки) |
| `dotnet run -- zero` | zero/0/log | zero.log (1 строка) | zero.log (1 строка) |
| `dotnet run -- upper` | x/10/LOG | 0 строк | 0 строк |
| `dotnet run -- empty` | пустой массив | 0 строк | 0 строк |
